ПУБЛІЧНА ВЕРСІЯ ДЛЯ RENDER

1. Створи новий репозиторій на GitHub.
2. Завантаж УСІ файли з цієї папки в корінь репозиторію.
3. На render.com створи New -> Web Service.
4. Підключи GitHub і вибери свій репозиторій.
5. Runtime: Node.
6. Build Command: npm install
7. Start Command: npm start
8. Plan: Free.
9. Натисни Create Web Service.
10. Після deploy Render покаже публічне посилання виду:
    https://назва.onrender.com

ВАЖЛИВО:
- Це ручний симулятор, а не офіційна система оповіщення.
- Кожен відвідувач тестує тривоги у своєму браузері.
- Запущена одним користувачем тестова тривога НЕ з'являється автоматично в інших.
- Пошук OpenStreetMap тепер запускається лише кнопкою «Знайти» або Enter, не на кожну літеру.

КАРТА ТРИВОГ УКРАЇНИ — РУЧНИЙ СИМУЛЯТОР V2

ВАЖЛИВО: це ручна демонстрація, а не реальна онлайн-карта військових загроз.

Ваші звуки:
- Запис (13) -> audio/air_alert.mp3 — повітряна тривога (також використовується для ракетної загрози)
- Запис (14) -> audio/drone_alert.mp3 — дронова тривога / Shahed
- Запис (15) -> audio/all_clear.mp3 — відбій

Я підсилив гучність записів перед додаванням до сайту.

ЗАПУСК
1. Розпакуйте ZIP.
2. Відкрийте Terminal у папці.
3. Запустіть:
   node server.js
4. Відкрийте:
   http://localhost:3000

ПОШУК
- Почніть писати назву міста, села, селища або району України.
- Пошук виконується через OpenStreetMap/Nominatim без API-ключа.
- Стрілки ↑ ↓ переміщуються списком.
- Enter вибирає підсвічений результат.

ЕФЕКТИ
- Повітряна тривога: червоний колір + ваш звук №13.
- БпЛА / Shahed: жовтий колір + рухома мітка + ваш звук №14.
- Ракетна загроза: червоний колір + рухома ракета + ваш звук №13.
- Відбій: ваш звук №15.
- Масштаб: вибране місце, велика зона або вся Україна.
